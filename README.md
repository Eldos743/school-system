# SHAKIRT SCHOOL — учётная система частной школы

Прототип по техническому заданию: три панели на демо-данных за 2025–2026 учебный год,
интерфейс на казахском и русском языках.

| Панель | Что показывает |
|---|---|
| **Мұғалімдер панелі** (учителя) | KPI каждого учителя, приход на работу и опоздания, контроль уроков, выполнение заданий, прирост знаний учеников, кому нужна поддержка |
| **Оқушы панелі** (ученики) | посещаемость, успеваемость по четвертям, диагностические тесты, потребность в доп. занятиях, олимпиады и пробные ЕНТ, история связи с родителями |
| **Құрылтайшы панелі** (учредитель) | качество знаний школы, динамика классов, рейтинг KPI, удовлетворённость и жалобы родителей, кадровая стабильность, приём и уход учеников, своевременный приход учителей |

## Запуск

```bash
pip install -r requirements.txt
python manage.py seed      # создать базу с демо-данными (instance/school.db)
python manage.py run       # открыть http://127.0.0.1:5000
python manage.py export    # собрать статическую демо-версию в demo/
```

## Структура

```
school/
  schema.sql    — таблицы: учителя, классы, ученики, оценки, посещаемость, приход учителей,
                  контроль уроков, задания, диагностика, пробные ЕНТ, олимпиады,
                  связь с родителями, отзывы и жалобы, заявки на поступление
  seed.py       — генератор демо-данных
  metrics.py    — расчёт KPI и всех показателей (формула KPI описана в начале файла)
  charts.py     — SVG-графики
  i18n.py       — переводы kz / ru
  app.py        — страницы (Flask)
  templates/    — шаблоны панелей
```

## Формула KPI учителя (предложение для согласования)

| Компонент | Вес | Как считается |
|---|---|---|
| Контроль уроков | 30% | средний балл листа наблюдения (4 критерия × 25) |
| Прирост знаний | 25% | итоговая − стартовая диагностика: 0 п.п. → 0, +15 п.п. → 100 |
| Задания | 15% | доля заданий, сданных в срок |
| Приход вовремя | 15% | доля дней без опоздания: 80% → 0, 100% → 100 |
| Качество знаний | 10% | доля оценок «4» и «5» в последней четверти |
| Без жалоб | 5% | 100 − 25 за каждую жалобу родителей |

Поддержка нужна, если KPI < 65 или любой компонент < 50.
